# Free Monad Schedulers in Haskell

This repository contains my solution to **Assignment 3**, which explores the **Free monad** in Haskell and its use for representing and interpreting effectful computations as data.

## Overview

The assignment covers the following topics:

- Implementing the `Free` monad
- Viewing **rose trees** as `Free []`
- Tracing stateful computations using `Free (State s)`
- Implementing a **round-robin scheduler** with explicit `yield`
- Extending the scheduler to support **sleeping threads**

All implementations are written in **Haskell** and follow the provided assignment template and type signatures.
